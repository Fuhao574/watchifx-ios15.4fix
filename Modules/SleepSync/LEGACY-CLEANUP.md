# 旧实验迁移边界（待设备执行）

本文件定义迁移范围，不是通用卸载脚本。禁止整目录删除 TweakInject 或 WatchFix 偏好。
2026-11-22用户新授权后的设备记录见同目录README：旧注入组件已备份移出，正常模块哈希不变。

## 模块本身不依赖 SSH

运行链为 WatchFix App → 固定本机 persona 启动器 → launchd worker → 会话作用域组件。
OpenSSH 不参与开始、状态、取消、恢复。主机源码检查通过不等于已经完成卸载 OpenSSH 后的设备验收。

## 仅清理旧实验的预定范围

1. 先确认当前会话已 closed、没有运行中的 worker，保留本轮诊断和备份。
2. 对已知旧实验的两个完整文件对逐一核对原始 SHA256；未知内容停止，不覆盖或强删。
   - `WatchFix_FocusConfigCompatibility.dylib` / `.plist`
   - `WatchFix_HelloReadOnlyObserver.dylib` / `.plist`
3. 先撤下过滤器，再把对应库移至专用私有备份；核验原路径不存在。
   `/Library/MobileSubstrate/DynamicLibraries` 若链接到 TweakInject，不当作第二套文件处理。
4. 精确移走已关闭会话的 `cn.fkj233.watchfix.sleepsync.<UUID>.plist`，不匹配或操作其他作业。
   如该服务仍注册，需单独核验并退出；不能在移动文件时声称已卸载进程内代码。
5. 过滤器撤下后，只有按设备操作约定明确通知并执行相应服务重启，才能验证旧库不再加载。
   不为清理做额外身份候选发送或 Focus 配置发送。
6. 偏好中的旧安装状态需要通过精确的 App 配置迁移处理；不删除整个偏好文件。
   历史日志、备份、消耗凭据先保留，不把旧凭据重置为可再次发送。

## 必须保留

- AppsSupport 1.0.13、Messages 修复、正常 PairingCompatibility 行为。
- 手机和手表现有 Sleep 内容；不写配对、Focus 或系统数据库。
- 所有未知注入文件、其他模块及用户设置。
